# 🎯 TaskKeep: Focus & Todo

**TaskKeep** — это минималистичный и умный планировщик задач с фоновым таймером фокусировки, разработанный для максимальной продуктивности без лишнего хаоса. Интерфейс автоматически адаптируется под язык вашего браузера (поддерживаются **Русский** и **English**) и сохраняет выбранную тему.

## ✨ Особенности
- 📋 **Умный Топ-3 планировщик:** Записывайте три главные цели на день. Поля ввода имеют жесткий лимит в 60 символов для защиты верстки.
- 🔄 **Автоперенос «хвостов»:** Скрипт автоматически сверяет даты — при наступлении нового дня выполненные задачи стираются, а невыполненные долги бережно переносятся наверх нового списка.
- ⌨️ **Интеллектуальное управление:** Курсор автоматически встает в первое пустое поле при открытии, а быстрое переключение между строчками задач происходит по нажатию `Enter`.
- 🔊 **Встроенный аудио-сигнал:** При завершении отсчета в фоне расширение генерирует приятный звуковой перелив (ноты Ре и Ля) на встроенном синтезаторе браузера.
- 🗑 **Кнопка «Очистить всё»:** Мгновенно обнуляйте список задач, сбрасывайте чекбоксы и чистите локальный кэш в один клик.
- ⏱ **Кастомный фоновый таймер:** Устанавливайте любое время или используйте пресеты (25м, 5м, 15м). Таймер работает в фоне Chrome, даже если окно закрыто.
- 🌙 **Тёмная тема:** Удобное переключение режимов оформления с сохранением настроек.

## 🛠 Установка
1. Скачайте и распакуйте ZIP-архив из **Releases**.
2. В Chrome перейдите на `chrome://extensions/` и включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное расширение** и выберите папку проекта.

# 🌐 English Version

**TaskKeep** is a minimalist and smart task planner combined with a background focus timer, engineered to maximize your productivity without the clutter.

## ✨ Features
- 📋 **Smart Top-3 Planner:** Track your three primary goals for the day. Text inputs feature a rigid 60-character limit to safeguard the UI layout.
- 🔄 **Task Roll-Over:** Automated date tracking handles the reset — completed tasks are wiped on a new day, while uncompleted items are neatly carried over to the top.
- ⌨️ **Smart Focus & Controls:** The cursor dynamically focuses on the first empty input upon opening, and you can switch fields instantly with the `Enter` key.
- 🔊 **Built-in Audio Notification:** Once the focus timer hits zero, the extension plays a clean synthesizer tone (D and A notes) using native browser resources.
- 🗑 **"Clear All" Button:** Instantly wipe out all daily goals, uncheck checkboxes, and flush the local cache in a single click.
- ⏱ **Background Timer:** Set custom durations or toggle quick presets (25m, 5m, 15m) that run seamlessly via Chrome Service Workers even when the popup is closed.
- 🌙 **Dark Mode:** Fluid UI theme switching that automatically saves your styling preferences.

## 🛠 Installation
1. Download and extract the ZIP archive from **Releases**.
2. Go to `chrome://extensions/` in Chrome and enable **Developer mode**.
3. Click **Load unpacked** and select the project folder.
