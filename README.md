# 🎯 TaskKeep: Focus & Todo

**TaskKeep** — это минималистичное и стильное расширение для Google Chrome, которое объединяет в себе планировщик топ-3 задач на день и настраиваемый таймер фокусировки. 

Интерфейс автоматически адаптируется под язык вашего браузера (поддерживаются **Русский** и **English**) и сохраняет выбранную тему.

## ✨ Особенности
- 📋 **Топ-3 задачи:** Записывайте три самые важные задачи на день. Они сохраняются автоматически и не пропадут при закрытии вкладки.
- ⏱ **Кастомный таймер:** Устанавливайте любое количество минут для работы или отдыха. Поле ввода блокируется во время отсчета для защиты от случайных нажатий.
- 🔄 **Кнопка сброса:** Сбрасывайте таймер в один клик, если вас отвлекли.
- 🌙 **Тёмная тема:** Переключайтесь между светлой и темной темами для комфортной работы вечером. Выбранный режим запоминается.
- 🌐 **Локализация:** Полная поддержка русского и английского языков прямо «из коробки».

## 🛠 Установка в режиме разработчика

1. Скачайте этот репозиторий в виде ZIP-архива и распакуйте его на компьютере.
2. Откройте Google Chrome и перейдите по адресу `chrome://extensions/`.
3. В правом верхнем углу включите **«Режим разработчика»** (Developer mode).
4. В левом верхнем углу нажмите кнопку **«Загрузить распакованное расширение»** (Load unpacked).
5. Выберите распакованную папку с файлами проекта.
6. Нажмите на значок пазла на панели Chrome и закрепите расширение **TaskKeep**.

# 🌐 English Version

**TaskKeep** is a minimalist and stylish Google Chrome extension that combines a top-3 daily task planner with a customizable focus timer.

The interface automatically adapts to your browser's language setting (supporting **Russian** and **English**) and preserves your selected theme.

## ✨ Features
- 📋 **Top 3 Tasks:** Write down your three most important goals for the day. Tasks are auto-saved instantly and won't be lost when you close the popup.
- ⏱ **Custom Timer:** Set any duration in minutes for work or breaks. The input fields lock during the countdown to prevent accidental edits.
- 🔄 **Reset Button:** Instantly reset the timer with a single click if you get distracted.
- 🌙 **Dark Mode:** Seamlessly switch between light and dark themes for comfortable late-night productivity. Your choice is remembered.
- 🌐 **Localization:** Complete native support for both English and Russian languages right out of the box.

## 🛠 Manual Installation (Developer Mode)

1. Download this repository as a ZIP archive and extract it on your computer.
2. Open Google Chrome and navigate to `chrome://extensions/`.
3. Enable **"Developer mode"** in the top-right corner.
4. Click the **"Load unpacked"** button in the top-left corner.
5. Select the extracted project folder containing all the extension files.
6. Click the extension puzzle icon on your Chrome toolbar and pin **TaskKeep**.
