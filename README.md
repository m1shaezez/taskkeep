# 🎯 TaskKeep: Focus & Todo

**TaskKeep** — это минималистичное расширение для Google Chrome с топ-3 задачами на день и фоновым таймером, поддерживающее русский и английский языки.

## ✨ Особенности
- **Топ-3 задачи с чекбоксами** и сохранением состояния.
- **Фоновый таймер (Service Worker)** и системные уведомления.
- **Быстрые пресеты времени** (25м, 5м, 15м) и ручной ввод.
- **Тёмная тема** с запоминанием выбора и полная локализация.

## 🛠 Установка
1. Скачайте и распакуйте ZIP-архив из **Releases**.
2. В Chrome перейдите на `chrome://extensions/` и включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное расширение** и выберите папку проекта.

# 🌐 English Version

**TaskKeep** is a minimalist Google Chrome extension combining a top-3 task planner and a background focus timer with dual-language support.

## ✨ Features
- **Top 3 Tasks with Checkboxes** and auto-saved states.
- **Background Timer (Service Worker)** with desktop push notifications.
- **Quick Time Presets** (25m, 5m, 15m) and manual input.
- **Dark Mode** support and full localization.

## 🛠 Installation
1. Download and extract the ZIP archive from **Releases**.
2. Go to `chrome://extensions/` in Chrome and enable **Developer mode**.
3. Click **Load unpacked** and select the project folder.
